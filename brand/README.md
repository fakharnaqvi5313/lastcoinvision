# Brand assets

- [`lcv-logo.png`](lcv-logo.png) — master logo, 2048×2048, transparent background. A stylized
  "L" monogram in a metallic teal gradient, set inside a sci-fi/circuit-styled ring on a deep
  navy disc.

Sampled from the master logo (for reference — Phase F's `/brand` palette page should treat
these as a starting point, not final):

| Swatch | Hex | Use |
|---|---|---|
| Deep navy | `#0E2640` | disc background |
| Bright cyan | `#0EEBFD` | outer ring / accent |

This lines up with the top-level spec's brand direction ("deep navy + white base, single
accent — teal or gold"): this logo settles that choice as **teal/cyan**.

Used as the favicon and in the `/brand` page once the website (Phase F) exists; also
suitable for the docs site, explorer branding, and README.
