# lcv-voting-portal

A minimal, read-only Next.js UI over `x/voting`: look up an election plus its commit-reveal
results, or list electoral authorities — generated by `create-lcv-app --template
voting-portal`. No wallet required; all lookups go over REST.

## Prerequisites

A running LCV devnet with its gRPC-gateway REST endpoint reachable (default
`http://localhost:1317` — see the chain repo's `make devnet` target). Edit `.env.local` to
point at a different network.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.
