# lcv-dapp-cosmos

A minimal Next.js dApp that connects Keplr to LastcoinVision and displays the account
balance, generated by `create-lcv-app --template dapp-cosmos`.

## Prerequisites

A running LCV devnet with its Tendermint RPC (default `http://localhost:26657`) and REST
(default `http://localhost:1317`) endpoints reachable — see the chain repo's `make devnet`
target. Edit `.env.local` to point at a different network.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000, click "Connect Keplr", and approve adding the LCV chain if
prompted.
