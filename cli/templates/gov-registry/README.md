# lcv-gov-registry

A minimal, read-only Next.js UI over `x/registry`: look up a jurisdiction's authority
address, or an asset's details and transfer history — generated by `create-lcv-app --template
gov-registry`. No wallet required; all lookups go over REST.

## Prerequisites

A running LCV devnet with its gRPC-gateway REST endpoint reachable (default
`http://localhost:1317` — see the chain repo's `make devnet` target). Edit `.env.local` to
point at a different network.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.
