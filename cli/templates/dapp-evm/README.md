# lcv-dapp-evm

A minimal Next.js dApp that connects MetaMask to LastcoinVision's EVM and displays the
native LCV balance, generated by `create-lcv-app --template dapp-evm`.

## Prerequisites

A running LCV devnet with its EVM JSON-RPC endpoint reachable (default `http://localhost:8545`
— see the chain repo's `make devnet` / `make devnet-evm` targets). Edit `.env.local` to point
at a different network.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000, click "Connect MetaMask", and approve adding the LCV network if
prompted.
